# Equipment

Mise en place. Every new tool in the build arrives with the user's yes, before any code is written.

Pick the path and follow its file:

- **New project.** The repo is empty. Read [new-project.md](new-project.md).
- **New tool.** The stack exists and the task needs something it doesn't have. Read [new-tool.md](new-tool.md).

Either path ends when the user has confirmed the choice.
